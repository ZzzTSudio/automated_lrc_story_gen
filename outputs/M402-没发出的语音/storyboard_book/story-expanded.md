# 《没发出的语音》故事扩写（剧情审查稿）

**歌曲编号：** M402  
**锁定设计片长：** 300秒  
**镜头范围：** S01—S38，均为5—10秒  
**当前状态：** C.5 剧情审查门第1轮返工完成，待第2轮复审；本稿不是视觉放行稿，尚未建立角色、场景或首帧资产。

## 1. 原作事实、改编补充与制作假设

### 原作事实（不可改动的叙事锚点）

1. 顾言在旧城区经营修鞋铺；宋妍经营隔壁花店，二人是高中同学。
2. 宋妍离婚后常拿一双磨坏的白球鞋来修。两人恢复联系，却不问彼此这些年。
3. 宋妍将带女儿搬去另一座城生活。
4. 顾言在打烊后录语音，准备说自己从未把宋妍当普通朋友；女儿在店外喊“妈妈”打断他，他把语音存进草稿。
5. 搬家日宋妍送来一束剪掉根的向日葵，并说“以后别再等她路过”。顾言按住播放键很久，最后只说“路上小心”。

### 改编补充（用于把原作事件展开为可表演的300秒）

1. 故事压缩在“宋妍最后一次送修白球鞋”到“搬家当天”的连续两天，避免凭空增添长期恋情或新冲突。
2. 白球鞋、店门风铃、没有根的向日葵和未发送语音，成为同一条“停在门槛前”的视觉线索：修好的鞋能继续走路，顾言的话却停在草稿里。白球鞋在第二天只供宋妍确认修理进度，搬家日上午才由她正式取走。
3. 宋妍只以简短、克制的口吻说明搬家；顾言不追问离婚细节，也不要求她留下。二人的沉默是关系现状，不被解释成误会或阴谋。
4. 女儿始终是宋妍新的生活责任和行动时间表的具体提示，不承担撮合或阻止二人的功能。

### 制作假设（待审查后再作为视觉设计基础）

1. 顾言与宋妍均为成年高中同学；具体年龄、外貌、服装、花店布局和城市名称均未锁定，审查通过后才进入连续性设定。
2. 修鞋铺与花店相邻、可从各自门口看见对方门面；这是原作“隔壁”的空间化处理。
3. 影片不播放完整录音内容，只让观众听见顾言开头的告白和保存前的停顿，以避免超出原作的情感承诺。
4. 片尾的“路上小心”锁定为顾言发送的一条**短语音回复**：只表现他按住录音后说出的这句话及无字波形，不展示可读文字。此选择把原作的“回了一句”落实为可听见的行动，不补写额外承诺。
5. 女儿在隔壁花店门口等宋妍一起回家。宋妍在打烊后从花店走到相邻修鞋铺门外时，女儿从花店门口喊“妈妈”；顾言在已锁门的修鞋铺内听见。这只锁定原作的空间因果，不补写女儿的年龄、性格或动机。
6. 搬家日S24—S38为同一日上午连续场次。阴天散射光逐渐变亮；最后一镜是“搬家日稍后（上午）”，不是傍晚跳时。

## 2. 导演诊断：故事四问

| 问题 | 回答 |
|---|---|
| 顾言想得到什么？ | 在宋妍离开前，诚实地让她知道自己仍把她看得比普通同学更重要。 |
| 什么具体事实阻止他？ | 宋妍已经为自己和女儿做出搬去新城市的决定；两人多年未问出口的距离，使顾言没有资格把自己的告白变成挽留。 |
| 哪条新信息改变局面？ | 宋妍明确说出搬家计划，随后店外女儿的“妈妈”让顾言意识到她的行程和责任已在门外等着。 |
| 结尾主角做了什么选择？ | 顾言不发送录好的告白，只回复“路上小心”，把情感从索取她停留改成祝她安全离开。 |

## 3. 详细故事与分场剧本

### 第一场：一双旧鞋重新进门（00:00—01:03）

傍晚，旧城区的修鞋铺仍开着。门铃响起，宋妍把那双鞋底再次磨开、已有旧补痕的白球鞋放上柜台。顾言抬头认出她，没有立刻说破熟悉，只像对一位常客那样接过鞋。

宋妍（改编补充）：“又麻烦你了，还是这双。”  
顾言（改编补充）：“明晚来拿，底边我再压一遍。”

他低头修鞋，宋妍看见柜台抽屉里露出的旧校照盒，顾言随即把它收回去；二人不用解释也知道那是高中留下的东西。宋妍说明天会来确认鞋底，随后回到隔壁花店继续打理门口花桶。两人没有问这些年，但“明天再见”让这次相遇不只是一段氛围停顿。

### 第二场：她说要走（01:03—02:00）

第二天傍晚，顾言把刚修好的鞋装进纸袋，却留在自己这一侧的柜台内。宋妍按约来**确认修鞋进度**，手上仍有整理花材留下的细小划痕；她没有来取鞋。她没有绕弯子，只说自己下周会带女儿去另一座城，花店也会收掉。

宋妍（改编补充）：“下周就走，带孩子换个地方住。”  
顾言（改编补充）：“今晚再压一遍，明早你来拿。”

顾言答得像只在交代修理注意事项。他把纸袋留在柜台内侧，没有交到宋妍手里。宋妍只是用指尖压平袋角，点头说“好，明早”。顾言看着她穿过狭窄的巷子、回到隔壁花店，没追出去。

### 第三场：关店后的告白（02:00—03:02）

夜里，花店暗下去，修鞋铺只剩工作灯。顾言收工具、锁门、把那只修好的白球鞋放在柜台中央。他录下语音，反复起句，终于说出核心的话。

顾言（原作事实的直接表述）：“宋妍，我从来没有把你当成普通朋友。”

他停在下一句前。隔壁花店打烊后，宋妍从花店门口走过相邻的修鞋铺；女儿在花店门口等她一起回家，清楚喊了一声“妈妈”。顾言抬头，隔着已锁的玻璃门看见宋妍转回女儿身边。他没有出门，只把语音停在草稿。手机屏幕不呈现可读文字，只用录音波形停住和他的拇指保存草稿表达。

### 第四场：没有根的花（03:02—04:04）

搬家日上午，巷口有搬家纸箱和车门关上的声音。宋妍走进修鞋铺，手里是一束剪去根部、不能再栽种的向日葵。她把花放到柜台上，顾言把已经定好的白球鞋纸袋从工作台内侧取出，她才正式拿回纸袋。

宋妍（原作事实）：“以后别再等我路过。”

她的语气不请求承诺，也不要求顾言回答。顾言听见后没有辩解，手从纸袋边缘收回。宋妍笑了一下，转身离开。花留在柜台；同一上午的阴天光从门口渐渐变亮，修好的鞋已经跟着她离开。

### 第五场：没有发出的语音（04:04—05:00）

同一日上午稍后，顾言独自坐回工作台。他重新按住语音草稿的播放键，听到自己的开头，又在那句告白之后把播放停住。巷外的车启动，他让原本要说的长话继续留在草稿中，只录下一条很短的回复。

顾言（原作事实）：“路上小心。”

门铃不再响。顾言把向日葵放进一个普通玻璃瓶，给花倒水；没有根的花不能重新活过来，但此刻被妥善安放。镜头停在同一日上午的工作台上：修鞋锤归位，手机朝下，店内仍有一盏灯亮着。

## 5. 待确认项

1. 回复媒介已锁定为短语音回复：顾言按住录音，说“路上小心”，以无字波形和放下手机表达发送；不再作为待定项。
2. 原作只说宋妍“准备带女儿去另一座城生活”，没有给出搬家精确日期。本稿用“下周”“搬家日上午”承接原作；不需要补写城市或具体交通工具。
3. 原作未说明宋妍是否在第一天送修、第二天取鞋。本稿明确为：第一天送修；第二天傍晚确认进度并约定明早取鞋；搬家日上午正式取鞋。这是服务道具连续性的制作假设，不把“常来修”的习惯误演成只发生一次。

## 6. 审查放行要求

审查者须重点判断：第二天确认进度与搬家日上午正式取鞋是否完全连续；前71秒是否每段都有新信息或关系变化；女儿从相邻花店门口呼喊的空间因果是否自然；同一上午的光线与店铺状态是否统一；以及“无根向日葵—未发长语音—短语音‘路上小心’”是否服务同一结尾。得到 `pass_to_visual` 前，不建立角色、场景、样片或首帧。
