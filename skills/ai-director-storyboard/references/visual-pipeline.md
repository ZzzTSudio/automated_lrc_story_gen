# AI视觉连续性与首帧生成

仅在用户需要角色图、场景图、逐镜首帧或图生视频提示时读取本文件。

## 实拍质感的提示原则

真人项目的目标是未经美容修饰的现场叙事电影单帧观感，不是宣传海报、棚拍写真、游戏截图或建筑效果图。只描述观感，交付仍如实标注为AI生成。不要以堆叠相机品牌、`masterpiece / best quality / 8K / hyperreal / ultra-detailed` 来替代可见事实；这些词也不能用来验收真实感。

每镜从下面维度选取与当前画面相关的具体描述，写进实际发送的提示词，不要只把它们留在连续性文档里：

| 维度 | 正向描述要点 | 避免的生成痕迹 |
|---|---|---|
| 人物皮肤 | 近景保留符合年龄的细微肤色变化、适度毛孔与局部油光，五官自然不完全对称，发丝有粗细与少量散发；远景不强求看见毛孔 | 磨皮美颜、蜡像或塑料脸、瓷白均匀肤色、全脸湿亮、刻意放大的毛孔与老化纹理 |
| 衣服与身体 | 布料厚薄、织纹和哑光/反光符合材质，领口与肘部有受力褶皱，手指握物有压力，坐姿与站姿有重心 | 充气衣服、贴图式布纹、衣服悬空、僵硬模特姿势、手与物件穿插 |
| 布光与曝光 | 明确主光从哪扇窗或哪盏场内灯来、方向与软硬程度；背光侧保留合理阴影，接触处有遮蔽，亮部自然过渡；混合光只在现场确有不同光源时使用 | 所有人均匀补亮、凭空轮廓光、无来源的脸部聚光、过度HDR、固定青橙滤镜、假泛光 |
| 镜头成像 | 景别、相机高度、拍摄方向、人物距离与焦段相互一致；指定对焦对象，景深按叙事需要选择；失焦区域自然渐变，暗部保留合理层次 | 人像抠图式虚化、五官透视扭曲、全画面过锐、物体边缘白描、用虚焦或噪点掩饰CG感 |
| 空间与道具 | 比例与功能可信，脚/椅子/道具真实接触地面或桌面；按场所用途安排家具，只选少量合理的使用痕迹，描述关键器具的实际外形 | 展厅/样板间式空净、随机堆杂物冒充生活感、同款道具重复、错误用途的器具、无接触阴影、镜面反射与光源不符 |
| 表演与构图 | 像演员在情境里被摄影机捕捉的一瞬：有具体视线对象、手与身体的准备姿态，构图服务人物关系，背景人有各自注意力 | 所有人望镜头、并排陈列、广告式完美笑容、没有剧情理由的绝对对称、整排同表情同姿势 |

真实不等于脏、暗、糊或有颗粒。不要无故添加汗水、雀斑、伤疤、灰尘、旧物和噪点；不要改变角色既定外貌或场所的清洁要求。只有该景别可见、符合情境的细节才进入提示词。负面约束保持简短，优先明确应该出现的材质、光线和构图。

## 1. 建立连续性圣经

在首次生成前锁定：

- 身份：年龄、脸型、眼型、眉形、鼻唇、肤色、皮肤质感。
- 发型：长度、分缝、刘海、盘发方式、胡须状态。
- 体型：身高、肩宽、比例、姿态。
- 服装：颜色、材质、领口、袖型、鞋、配饰；明确哪些镜头允许变化。
- 道具：形状、材质、磨损、颜色和持有者。
- 场景：平面结构、门窗、家具、镜面、屏幕、主光方向。
- 影像：画幅、焦段范围、现实或闪回的色彩与颗粒。
- 实拍观感：按主要场景固定主光来源、明暗关系、肤质与衣料处理、常用机位和对焦策略。调色克制且前后一致，不默认加颗粒或强青橙色。

连续性描述要具体但不要堆砌无关审美词。

## 2. 角色设定图

默认使用16:9横版单人设定图：

- 左侧约40%：腰部以上半身细节，清楚展示脸、头发、妆容和服装材质。
- 右侧约60%：同一人物全身正面、90度侧面、背面，完整显示头到脚。
- 中性浅灰棚拍背景；柔和中性光；所有视图身份、比例、服装和配饰完全一致。
- 按真人选角/服装记录照的观感制作：正常皮肤纹理、真实衣料垂坠、不过度美化脸和身材；柔光仍应保留脸部体积与衣褶阴影，不做三维角色转面渲染。
- 无文字、标签、拼贴边框、水印和品牌。

先生成核心主角，再根据剧情需要生成配角参考。角色图完成后必须视觉检查，确认不同视图没有换脸、换衣或身体比例漂移，并检查皮肤与衣料是否像真人照片。参考图若已有明显塑料脸或CG感，先修正参考图，不能期待后续加一句“写实”就消除它。

引用时逐张说明“只取身份和服装，不取背景、棚拍布光、站姿、表情或多视图布局”。剧情图的人物视线和姿态必须重新依据该镜动作设置；多个配角不得复制主角的脸、衣服或姿势。

## 3. 场景锚点

为反复出现的空间先生成一个宽幅建立镜头，固定建筑结构、家具、门、屏幕、花艺和光源。角色可出现在锚点中，但后续引用时明确“仅引用空间，忽略锚点内人物”。

锚点采用真实场地勘景照的观感：空间尺寸与功能合理，主要光源有位置，物体有重量与接触阴影，材料反射不过分光洁。不为“电影感”把普通房间改成高级展厅，也不为“生活感”随意加垃圾或破损。重要设备尽量说明真实形态与使用状态；仅写“灰色仪器”等过泛名词时，先补足必要的外形特征，避免模型拿家电或装饰品代替。

每镜只继承本场景的固定结构和材质；明确可移动道具的增减。不要把其他场景的台灯、家具或装饰写进通用参考说明。

优先锚定主要现实场景、结尾会回到的场景，以及有镜子、玻璃、屏幕、门或复杂空间关系的场景。一次性闪回可只用文字设定。

## 4. 首帧提示结构

每个首帧提示按以下顺序组织。可以使用中文或英文，关键是把具体摄影事实写进去，而不是逐字套用所有字段：

```text
Use case: identity-preserve
Asset type: one photographic narrative-film frame <SHOT_ID>, 16:9 landscape; storyboard is its production use, not a drawing style
Input images: <逐张限定身份/服装或场景结构的作用；不继承角色参考的棚拍光、背景、展示姿态和多视图布局>
Primary request: <仅描述动作开始前可见的一个瞬间；出镜人数、实际位置、目光对象、身体重心、手和道具状态>
Scene continuity: <空间与时间连续性>
Appearance target: the look of an unretouched live-action narrative film frame photographed on location, ordinary real people within a believable physical space
Visible materials: <当前景别能看见的自然肤质、头发、衣料受力和关键道具材质；不要为远景堆毛孔等微观词>
Composition/framing: <景别、焦段、相机高度与方向；必要时补人物距离；明确对焦点和合乎空间关系的景深>
Lighting/exposure: <实际主光源、方向、软硬、阴影与反射；皮肤曝光自然，不无故全场补亮>
Physical contact: <镜内可见的手/脚/家具/道具接触、重力与遮蔽关系>
Continuity constraints: preserve exact identity, hairstyle, proportions, outfit and referenced location
Avoid: CGI or 3D-render appearance, illustration, beauty retouching, waxy skin, cutout blur, artificial HDR, showroom staging, camera-facing poses unless required by the scene
Output constraints: one single 16:9 frame; no collage, captions, readable generated text, logo or watermark
```

对输入图逐张标注角色。配角合并参考图必须明确使用左侧或右侧人物。引用顺序在同一批次保持稳定。

后续动作意图保留在 `motion` / `video_prompt` 中，不把整段动作终态塞入首帧。静态首帧也不能把人物冻结成展示姿势：应描述例如“手指刚停在杯沿旁、重心落在右腿、目光朝对话者”等一个当下姿态。

实拍质感的中文首帧示例（具体地点、人物与摄影参数均须按当前项目改写）：

```text
生成一张16:9横版的真人叙事电影单帧观感图片，不是分镜手绘或三维渲染。人物参考只用于锁定脸、发型、体型和衣服，不沿用灰色棚拍背景、正面站姿或均匀柔光。傍晚的普通办公室，唯一主要光源是画左窗外的柔和天光，窗的对侧保留自然暗部，木桌边缘和物件下有合理接触阴影。她坐在画右，身体略朝桌面，目光落在画左的画外对话者，右手松放在一张完整便笺旁，尚未拿起。保留符合年龄的细微肤色变化、少量散发和棉布肘部受力褶皱，不美颜、不加皮肤缺陷。中近景，50mm镜头，机位与坐姿眼睛等高，对焦在眼睛，桌面和背景随距离自然失焦，不做抠图虚化。像自然表演中被截取的一瞬，克制曝光与色彩，不看镜头、不摆拍、不加无来源轮廓光，不出现塑料肤质、CG材质、过锐边缘或可读文字。只输出一张单镜头画面。
```

## 5. 最终单段视频提示

用户可复制的最终提示必须自成一段，按 `SKILL.md` 的四字段格式合并场景、人物位置、摄影和动作，不要求用户拼接分散的栏目：

```text
[场景：夜晚的大学实验室，冷白顶灯是主要光源，白色实验台下保留自然阴影，家具与人物有真实接触关系。角色：林澄（图中左侧的人）、周屿（图中右侧的人），保留首帧的自然肤质、发型和衣服褶皱，不磨皮、不改变身份。镜头：真人实拍电影单帧的成像质感，双人中景，40mm镜头，眼平固定机位，大景深，两人面部清晰，背景层次自然。动作：周屿将实验记录本沿桌面缓慢推向林澄，对她说“明天帮我看一遍，好吗”；林澄注视他，手停在本子旁，两人表演自然不过度，不望向摄影机，本子不悬浮，背景结构稳定。]
```

“场景”保留足够的环境和光线信息，使该段能单独使用。“角色”位置必须以当前首帧验收为准；只有设定而尚未生图时，标明分镜书中的位置是构图目标。一个镜头只承担一个主要叙事动作，台词不另起一段。没有人物或台词时明确写出。常规自然眨眼、呼吸和衣料运动不算新增叙事动作。

保持 `visual`（静态首帧）、`motion`（后续动作）、`dialogue`（台词）的内部结构便于检查，但最终的 `video_prompt` 必须是一条合并完成的单段提示。内部 `generation_prompt` 用于生成图片，与 `video_prompt` 分开存储。

## 6. 精确文字与界面

LED屏、手机界面、邮件标题、直播人数和片尾字幕采用后期合成。首帧可以要求抽象界面、黑屏或无文字占位，但不要依赖图片模型准确写中文。

分镜书中标注后期文字原文、出现位置和持续时间，以及需要跟踪、反射或屏幕透视时的合成说明。

## 7. 批量生成策略

1. 角色设定图。
2. 场景锚点。
3. 三张不同复杂度的测试首帧：人物近景、双人关系镜头，以及项目中最难的低照度／道具接触／多人或反光镜头；同时测试真实感与连续性。
4. 按下方视觉验收检查样片。若有塑料脸、CG场景或棚拍摆姿，先针对参考图继承、光源、材质或构图修正，再扩展到整批；不要仅追加“更真实、8K”。
5. 每张成功后立即复制到稳定镜号文件名。
6. 记录失败项并单独重试，不重做成功项。
7. 生成结束后验证文件数量、尺寸和缺号，再做视觉总览抽查。

批量顺序可以按技术依赖而非叙事顺序执行，但最终文件必须按镜号排序。

## 8. 视觉验收

抽查必须覆盖开场人物和场景建立、核心道具特写、第一次信息反转、最复杂的多人动作镜头、闪回或特殊光线镜头，以及结尾回收镜头。

真人题材分别检查以下问题；只看“漂亮”“高清”或文件校验通过不算实拍质感验收：

- **人物**：脸是否仍像照片中的真人，肤质是否被抹平或刻意粗糙化，脸与脖子肤色、发际线及衣料是否自然？
- **光线**：面部高光、身体阴影、桌面投影是否能由同一组场内光源解释？是否把应有暗部全部补亮？
- **物理与空间**：手握物、脚落地、椅子承重是否可信；器具是否像其实际用途，空间是否误成展厅或3D样板间？
- **摄影与表演**：透视、焦点和景深是否相符；人物是否在与场景和对手交流，而不是站成角色展示图？
- **一致性**：角色身份与道具状态是否稳定；背景人是否复制主角；不同镜头是否忽然从现场光变成棚拍美颜光？

根据可见问题定点调整：皮肤太假就修人物参考或肤质处理，光线太假就减少无来源补光并说明真实光源，摆拍就修视线与身体重心，场景像渲染就修材料、功能与接触关系。不要靠统一加噪点、降清晰度或把所有背景虚化来掩盖问题。未实际生图时只能报告模板已更新，不能声称真实感已得到实测提升。

发现单张错误时做定点重生或编辑，不要无理由重生整批。允许后期解决的文字内容不应触发整图返工；身份、手部、关键道具和空间错误必须修复。
