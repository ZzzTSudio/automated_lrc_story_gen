# 导演与分镜工作流

## 1. 先做导演诊断

在拆镜前用最少文字回答：

- 主角此刻想得到什么？
- 谁或什么阻止她？
- 观众在每个阶段应该相信什么？
- 哪个新信息改变了人物权力关系？
- 结尾留下的是答案、代价还是新的选择？

删掉无法改变行动、关系或观众认知的信息。短片每一分钟都必须推进冲突、揭示人物或兑现前面埋下的视觉线索。

## 2. 建立情绪节拍表

先按戏剧变化拆成节拍，而不是按台词拆镜。每个节拍记录：

| 字段 | 作用 |
|---|---|
| 目标 | 人物想在这一段获得什么 |
| 阻力 | 对手、秘密、时间或空间如何阻止 |
| 信息变化 | 观众新知道了什么 |
| 情绪温度 | 亲密、怀疑、恐惧、失控、释然等 |
| 权力归属 | 谁控制局面，何时发生转移 |
| 视觉母题 | 戒指、红绳、门、反光、空椅等可重复元素 |

短剧常用结构可参考“建立常态→破坏常态→对质→线索反转→真相失控→代价→余味”，但不要把它当成固定模板。

## 3. 把节拍变成镜头

每镜只保留一个主要信息或动作。以下选择应由戏剧功能驱动：

- 大全景：建立人物与空间、表现孤立或权力距离。
- 中景／双人镜头：呈现关系、身体位置和权力变化。
- 近景：捕捉决定、迟疑、谎言或情绪破裂。
- 特写／插入：强调证据、道具、手势或不可逆动作。
- 主观镜头／反光：让观众和人物同时发现线索。
- 过肩镜头：明确攻守关系，并维持空间轴线。

不要为了“电影感”堆砌运镜。推近用于认知或情绪收紧；拉远用于关系疏离或真相后的空虚；横移用于权力重新排列；手持用于失控；固定镜头用于让表演和沉默承担重量。

## 4. AI视频时长设计

- 先确定目标总时长、目标模型限制和项目的常规镜头区间，再分配镜数。未指定时采用5—10秒。
- 5—6秒：动作、证据插入、突然反应、快速转折；信息必须单一明确。
- 7—8秒：短对白、双人攻守、情绪反应和简单运镜；这是多数叙事镜头的舒适长度。
- 9—10秒：空间建立、长呼吸、沉默、关系变化或需要完整表演弧线的镜头；画面内部必须发生可感知变化，不能只为凑时长。
- 低于5秒只用于有明确剪辑理由的闪切、冲击插入或动作碎片；默认不超过10秒。用户或目标模型给出不同硬限制时，以该限制为准。
- 长对白跨多个景别延续，使用J-cut、L-cut或画外音保持节奏。不要让角色为了塞入时长而高速念词，也不要为了达到区间下限而拖慢表演。
- 计算所有镜头时长之和，不以“约”等模糊表述交付。

## 5. 空间与轴线

为主要场景先画出简化平面关系：入口、出口、主光源、镜子、屏幕、关键道具和人物初始位置。记录人物面向和跨轴理由。

当剧情发生权力反转时，可以通过以下方式视觉化：

- 原本居中的人物被挤到画面边缘。
- 保护者站位变成封锁出口的位置。
- 前景道具遮挡由弱变强。
- 暖色实景切入冷色证据画面。
- 结尾回到相同构图，但改变人物距离或环境秩序。

## 6. 首帧与动作分开设计

首帧描述静态可见事实：人物、位置、表情、道具、环境、景别、镜头高度、镜头焦段和光线。动作提示只描述接下来数秒内的一个主要变化。

错误示例：同一镜头要求人物奔跑、转身、抢手机、打斗、开门和被捕。

正确做法：拆成“抢手机”“男主挡住”“真凶退到门边”“警察破门”四个独立镜头。

## 7. 声音与剪辑

声音不只是对白。分镜中标注：

- 现场声：衣料、钥匙落地、门锁、呼吸、宾客低语。
- 叙事声：电话录音、视频声、画外音、警笛。
- 音乐进入与退出：真相揭露时停音乐往往比加重音乐更有效。
- 转场桥：上一镜声音提前进入下一镜，或下一镜画面先出现再延续上一句对白。

## 8. 导演自检

- 去掉任意一个镜头，剧情是否仍完全不受影响？若是，该镜头可能多余。
- 反转是否有提前出现的视觉证据，而不是靠人物突然解释？
- 每次景别变化是否对应信息、关系或情绪变化？
- 结尾是否回收了至少一个开场意象？
- 主角最终做出了自己的选择，而不是只被真相推着走？
